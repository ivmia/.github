# IVMIA Technology

Technology company based in Istanbul, working on enterprise software, artificial intelligence, process automation and data infrastructure for clients in Türkiye and abroad.

We build software around how a team actually works: document capture and data extraction, management dashboards, system integration, enterprise AI assistants, workflow automation and modernisation of legacy systems. We stay involved after launch.

What we publish here is the small, self-contained code we found ourselves rewriting for every project. Each repository stands on its own, has no dependencies beyond PHP or Python itself, and carries its own tests.
